Comandos Utilizados y sus Funciones:

- git init: Crea un repositorio de Git en la carpeta en la que se esté ubicado en la terminal.

- git add: Coloca los archivos seleccionados (o todos con el .) a una zona de preparación o stage para preparar los archivos con el fin de hacer el commit.

- git commit: Guarda los cambios de los archivos preparados con add haciendo un punto de guardado listo para subirse a GitHub.

- git push: Sube los commits tomados a un repositorio en GitHub previamente conectado al proyecto en local para que quede seguro en el repositorio y más personas puedan trabajar con él.

- git status: Muestra el estado del proyecto, mostrando los archivos modificados o en opción para commitear.

- git diff: Muestra el cambio exacto de las líneas nuevas agregadas en un documento.

- git log: Muestra el historial de commits del proyecto con el código, autor, correo, hora y fecha de los mismos. Y tiene su versión abreviada en la que solo se muestran los commits realizados del más nuevo al más antiguo.

- git restore: Te permite recuperar un archivo después de haberlo modificado para regresar al original en dado caso de cometer errores o querer regresar a donde se estaba trabajando originalmente.
